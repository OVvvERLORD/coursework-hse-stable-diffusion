# Курсовая работа: имплементация Stable Diffusion.
![Language](https://shields.io/badge/-Rust-3776AB?style=flat&logo=rust)
![Mentor](https://img.shields.io/badge/CUDA-76B900?logo=nvidia&logoColor=white)

Инженерно-исследовательский проект по низкоуровневой имплементации компонентов диффузионных моделей (**Stable Diffusion**) на языке Rust с нуля. 
Проект разработан в рамках курсовой работы НИУ ВШЭ под индустриальным менторством **Senior Engineer из NVIDIA**. Фокус работы смещен со стандартного высокоуровневого прототипирования на глубокую оптимизацию производительности — создание кастомной архитектуры **U-Net** с поддержкой CUDA-ядер.

---

## Описание

Изначальная цель — перенос классического пайплайна генерации на стек Rust. В процессе исследования совместно с ментором было принято решение сфокусироваться на самом вычислительно сложном и критичном для latency блоке — механизме денойзинга.

Проект представляет собой кастомную реализацию идей и архитектурных подходов из фундаментальных статей:
1. **U-Net**: *«U-Net: Convolutional Networks for Biomedical Image Segmentation»* (Ronneberger et al.)
2. **DDPM / Stable Diffusion**: *«Denoising Diffusion Probabilistic Models»* (Ho et al.)

---

## Архитектура


### Ключевые особенности реализации:
* **Encoder/Decoder на Rust**: Безопасное управление памятью, аллокациями и жизненным циклом тензоров средствами системы типов Rust.
* **Использование CUDA ядер**: Перенос тяжелых математических операций на GPU.

---

## 🛠 Технологический стек и структура

* **Язык**: Rust
* **Ускорение**: NVIDIA CUDA C++ 
* **Бенчмаркинг**: Директория `benches/` 

### Структура репозитория:
* `src/` — Логика слоев U-Net, обертки над CUDA API, управление вычислительным графом.
* `benches/` — Изолированные тесты производительности.
* `scripts/` — Вспомогательные утилиты.

---

## 🚀 Как запустить

### Требования
* Rust (MSRV 1.75+)
* NVIDIA CUDA Toolkit (12.x+)
* Компилятор `nvcc` в системном `PATH`

### Сборка проекта
```bash
cargo build --release
```

### Тестирование
```bash
cargo bench
```
